APPENDIX 01 · 시스템 기술 아키텍처

스마트폰 BLE → 허브 → 개별제어 → 앱

포함 내용
스마트폰 BLE · 구역별 ESP32-S3 · Raspberry Pi 4B MVP 허브 · 공간 판단 알고리즘 · 개별 플러그 제어 · 공유기 송신출력 최적화 · 서버·DB·앱 연결 · 로컬 제어와 클라우드 역할 구분
답변 원칙
다중 사용자 — 등록된 스마트폰 단위로 판단하므로, 한 공간에 여러 인원이 있어도 등록기기 중 1대 이상이 감지되면 해당 공간을 사용중으로 판단합니다. 인원을 개별 구분하는 기능은 아닙니다.
정지 상태 — BLE는 동작이 아닌 주기적 신호 송출이 근거이므로, 동작센서와 달리 가만히 있어도 재실 판단 자체는 가능합니다. 실제 정확도·오판율은 5가구·30일 실증에서 검증합니다.
대비 질문: 여러 사람이 있을 때는? · 인터넷이 끊기면? · 사용자가 가만히 있어도 판단되는가?

APPENDIX 02 · 안전 기본값과 자동제어 제외기기

허용한 기기만, 신뢰도가 낮으면 확인부터

  • 고객이 자동 OFF를 허용한 기기만 제어
  • 냉장고·의료기기·인덕션 등은 자동제어 대상에서 제외
  • 위치 판단 신뢰도가 낮으면 자동 차단하지 않고 사용자 확인
  • 통신 장애 시에도 BIUM 허브의 로컬 제어 로직 유지
  • 건물 배선·분전반 문제는 전기 전문업체로 연결
  • 전기화재를 예방·진단·보장한다고 약속하지 않음
